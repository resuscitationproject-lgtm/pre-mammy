# ITクラブ × プレマミ「まなびのぼうけん」試作版

幼稚園〜小学3年生向けの国語・算数学習ゲームです。iPad の Safari で使える静的 Web アプリとして作成しています。

## 動かし方

このフォルダで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。GitHub Pages に置く場合、追加のビルドは不要です。

`npm test` で出題と達成条件を確認できます。

## できること

- 幼稚園、小学1〜3年生の問題を選択できます。
- 国語は最初のひらがな、漢字の読み。算数は足し算、引き算、掛け算、割り算を出題します。
- 正解数または学習時間のどちらかで、当日の目標達成を表示します。初期値は30分または10問です。
- 学習時間は問題画面が表示され、最後の操作から60秒以内で、画面が前面にある場合だけ加算します。
- 記録は iPad のブラウザ内に保存し、日本時間の日付が変わると当日の記録を更新します。

## 現時点の限界

この試作版の「達成」は画面表示だけです。YouTube、ゲーム、TikTok などの端末アプリをロック・解除する機能はありません。ブラウザの保存データは子どもが削除・変更でき、保護者設定にも認証はありません。時間も学習内容の理解度を保証するものではありません。

### Google サイトと GitHub Pages

Google サイトを「制限付き」で公開し、指定した家庭だけに入口を見せられます。ただし、ゲームを普通の GitHub Pages に公開するとゲーム本体は URL から直接開けます。Google サイトの閲覧権限は、別ドメインの GitHub Pages には引き継がれません。児童別の学習記録や確実なアクセス制御には、認証付きの配信先とサーバー側の記録が必要です。

1. GitHub リポジトリにこのフォルダを登録し、Pages の公開元を対象ブランチの `/ (root)` に設定します。
2. 公開された URL を Google サイトのボタンに設定します。埋め込みも可能ですが、iPad ではボタンから全画面で開く形が扱いやすいです。
3. Google サイト側で「公開済みサイト」の閲覧者を「制限付き」にし、保護者の Google アカウントを追加します。
4. 子どもの氏名、写真、学習履歴、認証情報は公開 GitHub リポジトリや Pages に置かないでください。

### iPad の制限を実現する方法

ショートカットには「アプリを開いたとき」の自動化があります。対象アプリ起動時に学習ページを開く試験はできます。ただし、ショートカットだけでは保護者が定めたアプリ制限を確実に強制できず、Web アプリ内の記録を安全に読んで解除する仕組みもありません。試験時は保護者が端末を管理し、スクリーンタイムのパスコード、休止時間、アプリ使用時間を併用してください。これは学習達成による自動解除ではありません。

企画の中心である「学習達成までは対象アプリを制限し、達成時に自動解除」を実現するには、iPad のネイティブアプリが必要です。Apple の **Family Controls** で保護者承認を得て対象アプリを選び、**Managed Settings** でシールドを設定し、学習達成時にシールドを解除する構成が妥当です。端末上で改ざんしにくい達成判定と設定保存、保護者画面、Apple の entitlement 申請、実機検証が必要です。Google サイトは案内・会員入口、GitHub はソース管理として残せます。

## 次に決めること

実運用前に、対象 iPad の OS バージョン、家庭ごとの Apple Account / ファミリー共有、対象アプリ、学年別の問題数と難易度、時間目標の扱いを決めます。幼稚園児に30分を一律で求める設計は避け、保護者が短い目標を選べるようにしています。
